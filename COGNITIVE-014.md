# NEXUS 0.14 Cognitive Lab
Independent Android research edition. Original 0.13 branch and archived source are unchanged.
64 action-conditioned MLPs (144→128→128→4), 2,277,632 parameters, fixed sparse routing (four per candidate), four bounded outcome estimates, disagreement penalty, online supervised learning from simulator outcomes, bounded replay, atomic checkpoint and evaluation without weight updates. Eight expert groups. Grid observations are structured simulation state, not vision. The arena uses abstract beacons, supplies, a vehicle and randomized layouts. No external app automation, screen capture, OCR, trained object detection, video imitation, self-play or full professional gameplay is implemented. The 0.13 APK and video/supply code are not integrated into this edition. Debug APK uses independent application ID co.nexus.research.cognitive. Training pauses on leaving the activity or severe thermal status. No claim of competitive performance.
Build: JDK 17, Android SDK 35, Gradle 8.9. GitHub Actions tests Java and signs/verifies debug APK.
