# NEXUS 0.16 Review Lab
Built on 0.15, retains its 412 sparse networks and the 0.14 laboratory. Local simulator only.
- StrategyLab forks the deterministic local arena, evaluates up to four-step sequences and compares demonstrations against alternatives. A score gap is a potential error according to the local simulator objective, not professional player judgment. A read-only review does not train; verified demonstration import trains the same decision model used in the arena.
- NXDEMO1 plain text: header, seed, then one local action enum per line. Export a trace from the app or recover a contiguous sequence of NXD markers via OCR from a recording of the local simulator; missing/contradictory markers prevent import. The user must select the detected-demo import option. No arbitrary video-to-game action inference.
- Video foreground service processes at most 96 frames per clip, saves visual predictions in a separate checkpoint, emits timestamps, OCR text, generic labels and visual prediction error. Generic labels are not game-specific object detection. The service stops on severe heat or user cancellation, and is not guaranteed to survive process termination. Background analysis and simulator use separate model files. The prior 0.15 video weights remain in its checkpoint but are not migrated into the independent video service.
- INT8 weight approximation in evaluation uses dequantized multiplications; training retains Float32 weights and there is no hardware INT8 execution. Optional disk LRU limits resident networks to 32 (unless write fails), restores exact Float32 weights, canonical checkpoint retains all trained networks. The cache is temporary and can grow across activity restarts. Checkpoint still loads all trained weights before enabling cache.
- No external game automation, no Free Fire integration, no validated professional strategy extraction, no game-specific detector, no self-play. Not tested on physical A21S. Debug signing may differ from previous build; avoid uninstalling without considering checkpoint loss.
- Bundled ML Kit Latin OCR and generic image labeling. CI tests pure Java learning, strategy, cache and quantization, compiles and verifies APK. Android video/OCR behavior requires device testing.
