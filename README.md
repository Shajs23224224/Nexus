# NEXUS Research 0.6

Rama inicial de investigación Android: agente autónomo Q-learning tabular en una arena local fija, persistencia atómica, evaluación sin entrenamiento, pausa térmica y al salir. No es la migración completa del ZIP 0.5: su red neuronal, IPC y recursos visuales originales no están incluidos en esta versión de GitHub. No controla Free Fire ni aplicaciones externas. Requiere JDK 17, Gradle 8.9 y SDK 35. GitHub Actions incluye prueba de aprendizaje/persistencia y compilación debug. Resultados de compilación pendientes de verificar.
